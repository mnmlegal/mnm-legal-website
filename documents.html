Security and Confidentiality

Document handling safeguards.

  • Firebase authenticated administrator access.
  • Firestore security rules restrict metadata access.
  • Google Drive authorization is required for original file operations.
  • Google access tokens are not stored in browser persistent storage.
  • Document version history is retained within the application.
  • Archival replaces permanent deletion through this interface.

Google Drive sharing permissions must remain private. Files may still be modified or deleted outside this application by authorized Drive users. This system is not a tamper-proof forensic evidence repository.
